BallTree Ball Mapper — benchmark vs pyballmapper

host=Hahn · cores=16 · reps=3 (median) · 2026-06-30 19:14

FastBallMapper replaces the reference algorithm's serial O(N·L) distance loop with an sklearn BallTree (landmark selection & coverage) and a sparse incidence-matrix product M @ MT for edges. It is a drop-in replacement: same public API and a mathematically identical graph.

All tested ε produce a graph identical to pyballmapper.BallMapper (same landmark point-ids and same edge set) — the speed-up is free of any accuracy cost.
